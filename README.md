# 🤖 Spectra Bot

Bot WhatsApp otomatis menggunakan Node.js dan library `whatsapp-web.js`.  
Bisa membalas perintah, membuat stiker, hingga mengelola grup.

## 🚀 Fitur

- ✅ Balas perintah seperti `!ping`, `!help`
- ✅ Buat stiker dari gambar/video
- ✅ Promote/demote admin grup
- ✅ Kick anggota grup
- ✅ Kirim meme random
- ✅ Session tetap tersimpan (tidak perlu scan QR tiap restart)
